## Overview

Auto Trash is a Terraria quality-of-life mod that lets players configure a blacklist of items to automatically delete when picked up, preventing junk materials like broken armor pieces, low-value vendor trash, and excess common drops from filling inventory during mining and combat sessions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Auto Trash** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Auto-Delete List** | Configure items to automatically delete when picked up from the world |
| **Whitelist Mode** | Optionally invert to only keep whitelisted items and trash everything else |
| **Hotkey Toggle** | Hotkey to quickly pause or resume auto-trash without opening settings |
| **Mod Item Support** | Works with any custom items added by installed Terraria content mods |
